# Arquivos de suporte

Esta pasta reune itens auxiliares que nao precisam ficar espalhados na raiz.

```text
suporte/
|-- config/
|   `-- configuracao.env
|-- documentacao/
|   |-- DOCUMENTACAO_PROJETO.md
|   `-- README_API.md
`-- scripts/
    |-- gerar_apk.cmd
    `-- iniciar_api.cmd
```

- `config`: endereco da API e credenciais do MySQL.
- `documentacao`: explicacoes sobre o aplicativo e a API.
- `scripts`: atalhos para iniciar a API e gerar o APK.
